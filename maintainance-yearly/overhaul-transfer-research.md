# 📋 รีเสิร์ช — กระบวนการโอนย้าย/จำหน่ายรถขนาดใหญ่ (ต่อยอดจาก Overhaul)

> **สถานะ:** เก็บไว้เป็นข้อมูลตั้งต้นก่อนลงมือคุยกับหน่วยงาน — **ยังไม่ใช่ requirement ที่ยืนยันแล้ว** (14 ก.ย. 2569)
> **ที่มา:** ต่อยอดจากฟีเจอร์ **Overhaul** (`overhaul.js` เพิ่ม 8 ก.ย. 2569) ซึ่งจบแค่ "รายการรถที่เข้าข่าย + เหตุผล" — รถที่ตั้งธง "รอจำหน่าย/หมดสภาพ" (`r.disposalFlag`) ยังไม่มี flow ต่อว่าจะ **โอนย้าย** ไปหน่วยงานอื่น หรือ **จำหน่าย** ทิ้ง
> **สโคป:** เฉพาะรถขนาดใหญ่ (กระเช้า/เครน/รถขุด) ตามขอบเขตเดิมของ Overhaul — ยังไม่รวมรถเล็ก

**กำกับที่มาทุกข้อ** — `✅ ภายใน` = ข้อเท็จจริงจากโค้ด/schema จริงของโปรเจกต์นี้ · `🌐 เว็บ` = กรอบทั่วไปจากระเบียบ/คู่มือราชการ (ไม่ใช่ระเบียบเฉพาะของ PEA) · `❓ ต้องถาม` = ยังไม่มีคำตอบ ต้องไปถามหน่วยงาน

## 2. กรอบทั่วไปจากระเบียบราชการ/รัฐวิสาหกิจ 🌐

- **ระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560** (+ฉบับที่ 2 พ.ศ. 2564): **"โอน" ถูกนับเป็นรูปแบบหนึ่งของ "การจำหน่ายพัสดุ"** (คู่กับขาย/แลกเปลี่ยน/แปรสภาพ/ทำลาย) ไม่ใช่กระบวนการแยกขาดจากกัน — [ระเบียบฉบับที่ 2 พ.ศ. 2564 (PDF)](https://www.gprocurement.go.th/wps/wcm/connect/30b2077c-5c96-459d-9f98-28a696819738/ระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ+(ฉบับที่2)+พ.ศ.+2564.PDF)
- คู่มือหน่วยงานรัฐทั่วไปใช้โครงเดียวกัน: **ตั้งกรรมการตรวจสอบ → ประเมินสภาพ/มูลค่า → เสนอผู้มีอำนาจอนุมัติ → ทำเอกสารโอน/รับโอน → ปรับปรุงทะเบียนทรัพย์สิน**
  - [คู่มือการจำหน่ายพัสดุประจำปี (dopa.go.th)](https://multi.dopa.go.th/audit/assets/modules/news/uploads/7fb8a02c42c795387f7d23806f1bf530650aaf61005479139898753829195678.pdf)
  - [คู่มือการรับโอนสินทรัพย์และการรับบริจาค (suphan.go.th)](https://www.suphan.go.th/customers/webpage/datas/content/download/250401/7c5a86fd.pdf)
- นิยาม "โอน" ที่ใช้แพร่หลายในหน่วยงานรัฐ: มอบสิทธิครอบครองไปยังส่วนราชการ/รัฐวิสาหกิจ/องค์การสาธารณกุศลอื่น
- PEA มีหน้าระเบียบของตัวเอง (https://www.pea.co.th/about-pea/rules-and-laws) แต่ **ค้นเว็บไม่เจอระเบียบโอนย้ายยานพาหนะฉบับจริงที่เปิดเผยสาธารณะ** — ต้องขอจากภายใน (ดูข้อ 4)

## 3. รายการคำถามที่ต้องถามหน่วยงาน ❓

**เงื่อนไข/จุดเริ่มต้น**
- โอนย้ายกับจำหน่ายต่างกันตรงไหนในทางปฏิบัติจริงของ PEA (กฎหมายกลางนับโอนเป็นการจำหน่ายแบบหนึ่ง — PEA แยกกระบวนการหรือใช้ร่วมกัน)
- อะไรกระตุ้นให้เกิดการโอนย้าย (หน่วยงานต้นทางเลิกใช้/ยุบหน่วย, ปลายทางขาดแคลน, ผลจากการประเมิน Overhaul ว่ารถยังใช้ได้แต่หน่วยงานเดิมไม่ต้องการ)
- เกณฑ์ตัดสิน "ควรโอนย้าย" กับ "ควรจำหน่าย" ต่างกันตรงไหน

**ผู้เกี่ยวข้อง/สายอนุมัติ**
- ใครริเริ่มคำขอ — ต้นทาง ปลายทาง กบค. หรือฝ่ายพัสดุกลาง
- สายอนุมัติกี่ขั้น ใครเซ็น — เหมือนหรือต่างจากสายอนุมัติปิดแผนบำรุงรักษาที่มีอยู่แล้ว (หัวหน้า → กรย. → กบค.)
- หน่วยงานปลายทางปฏิเสธไม่รับโอนได้ไหม

**เอกสาร/ข้อมูล**
- ใช้แบบฟอร์มอะไรบ้าง (บันทึกขอโอน / รายงานสภาพ-มูลค่า / บันทึกรับโอน)
- ต้องประเมินสภาพ/มูลค่าก่อนโอนไหม ใช้ชุดประเมินเดียวกับ Overhaul หรือคนละชุด

**ผลต่อข้อมูล/ระบบ**
- โอนแล้วรหัสครุภัณฑ์เปลี่ยนไหม — และแอปนี้แค่ "อ่าน" ค่าที่ SAP อัปเดตให้ หรือต้องมีจุดกดโอนในแอปด้วย
- ประวัติซ่อม/แผนบำรุงรักษาเดิมติดไปกับรถ หรือเริ่มใหม่ที่หน่วยงานปลายทาง
- ถ้ารถอยู่ในแผนไตรมาสปัจจุบันตอนโอนพอดี ต้องดึงออกทันทีไหม (เทียบกติกา "รถอยู่ได้ไตรมาสเดียว" ที่มีอยู่แล้ว)

**เฉพาะรถขนาดใหญ่**
- กระเช้า/เครน/รถขุด มีขั้นตอนต่างจากรถทั่วไปไหม (ตรวจสภาพเฉพาะทาง, ใบอนุญาตพ่วง/ขับเฉพาะทางต้องโอนตามไหม)
- ข้อจำกัดพื้นที่/ระยะทางทำให้โอนข้ามเขตยากกว่ารถเล็กไหม

**ระยะเวลา/Edge case**
- ใช้เวลาเฉลี่ยเท่าไรตั้งแต่ขอจนโอนเสร็จ
- รถกำลังซ่อมอยู่ตอนมีคำขอโอน ทำยังไง
- โอนแล้วยกเลิกกลางทางมีขั้นตอนย้อนกลับไหม

## 4. วิธีหาคำตอบจากมากกว่า 1 แหล่ง

1. **ฝ่ายพัสดุ/บัญชีทรัพย์สินกลาง PEA** — เจ้าของกระบวนการจริงตาม พ.ร.บ. 2560
2. **ทีม กบค./ผู้ทำแผนบำรุงรักษา** — คนใช้หน้าจอนี้จริง ถามผลกระทบต่อแผน/ประวัติซ่อมโดยตรง
3. **ขอเอกสาร "ระเบียบ กฟภ. ว่าด้วยการพัสดุ"** จากภายใน — เว็บสาธารณะหาไม่เจอฉบับตรง
4. **ทีมดูแล SAP/ระบบสินทรัพย์** (เจ้าของ `v_car_asset_found_vms`) — ยืนยันว่าแอปนี้ต้องอ่านอย่างเดียว หรือเขียนกลับ (SAP) ด้วย
5. **เทียบเคียงคู่มือรัฐวิสาหกิจ/ราชการอื่น** ที่แนบลิงก์ไว้ข้อ 2 — ใช้ตั้งกรอบคำถามล่วงหน้า ไม่ใช่คำตอบสุดท้าย
6. **Government Open Data**: [dataset การจำหน่ายยานพาหนะ](https://gdcatalog.go.th/dataset/gdpublish-dataset-11-501) — เผื่อมีตัวอย่างฟอร์ม/โครงข้อมูลที่หน่วยงานรัฐใช้รายงานจริง

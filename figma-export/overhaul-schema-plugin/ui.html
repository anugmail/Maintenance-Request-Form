Overhaul schema annotator

เลือกตาราง (หรือเฟรมที่ครอบหัวตาราง) ที่ overhaul2-plugin สร้างไว้ในหน้า Figma แล้วกด "แปะ schema ที่เลือก" — จะมีป้ายเล็กๆ ใต้หัวคอลัมน์ที่จับคู่ได้ บอก DB/PARTIAL/GAP/EXTERNAL/NEW พร้อม table.column จริง

ยังไม่ได้ทำอะไร

เขียน AC ลงหน้า จากตารางที่เลือก — สร้างเฟรม "AC draft" ขึ้นข้างสิ่งที่เลือกเลย (ไม่ใช่ copy ไปวางที่อื่น) เป็น Rule list (เฉพาะ field ที่มี rule จริง) + Flow (ถ้ามีเก็บไว้ให้)

หรือ — ไม่ต้องเลือกอะไรเลย สร้าง AC ของ ทุก scenario ใน AC_FLOWS รวดเดียว (เรียงซ้อนคอลัมน์เดียวจากมุมบนซ้ายของหน้า)

DB — มี column จริง ความหมายตรง
PARTIAL — มี column แต่ไม่ตรงทั้งหมด (format/semantics)
GAP — ไม่มี column/ตารางรองรับเลย
EXTERNAL — มาจาก vms_mas_vehicle/main-be ไม่ใช่ repo นี้
NEW — derive จากตารางลูกที่มีอยู่แล้วได้ (ไม่ใช่ column ตรง)
RESOLVED — เคยดูเหมือน gap แต่ตรวจซ้ำแล้วไม่ใช่ gap จริง (ทีมเคาะปิดแล้ว)
หัวคอลัมน์ที่ปลั๊กอินนี้รู้จัก (ถ้าไม่เจอ แปลว่าข้อความไม่ตรง key)

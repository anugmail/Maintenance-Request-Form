วิธีใช้
สร้างจอ
  1. ติ๊ก Feature (หลายตัวได้ หรือเลือกทั้งหมด) และเลือกอุปกรณ์
  2. จะเอาบาง journey กดลูกศร › ท้ายแถว Feature แล้วติ๊กเฉพาะ journey ที่ต้องการ
  3. กด สร้าง หรือแท็บส่งไป FigJam กด ส่ง Feature ที่เลือก (ใช้ journey ที่ติ๊กเหมือนกัน)
  4. รอแถบด้านล่างขึ้น เสร็จ จอจะอยู่ใน Page ของ Feature นั้น (ดูชื่อใต้ชื่อ Feature · เปิดได้จากแถบ Pages ทางซ้ายของ Figma · ยังไม่มีปลั๊กอินสร้างให้)
ส่งไป FigJam
  1. เปิด node figma-export/serve.js ในเทอร์มินัล
  2. แท็บ ส่งไป FigJam วางลิงก์บอร์ด กด เพิ่ม (ครั้งแรกครั้งเดียว)
  3. กด ส่งทุก Feature ไป FigJam แล้วกด เปิดบอร์ดปลายทาง
  4. ในบอร์ด รันพระผู้สร้าง กด วางลงบอร์ดนี้
อัปเดต / ลบ
  1. ติ๊ก Feature / journey / อุปกรณ์ ในแท็บสร้างจอ
  2. ตรวจจอที่เปลี่ยน ดูจำนวน แล้วกด อัปเดต — สร้างใหม่เฉพาะจอที่โค้ดเปลี่ยน วางที่เดิม
  3. จอที่สร้างก่อนมีระบบตรวจ ปลั๊กอินเลือก สร้างใหม่ ไว้ให้ (ครั้งเดียว ครั้งต่อไปตรวจได้)
  4. อยากทำบางจอ: เลือกเฟรมจอใน Figma แล้วกด สร้างจอที่เลือกใหม่
  5. ลบส่วน: ติ๊ก Happy flow / ทุกเคส กด ตรวจก่อนลบ แล้วยืนยันจำนวน
ควรรู้
  • ปลั๊กอินตรวจไม่ได้ว่าจอไหนเปลี่ยน (ไม่มีกล่องยืนยัน) ให้ใช้สร้างใหม่ทุกจอ หรือเลือกจอแล้วสร้างใหม่
  • ไม่ทับของเดิม กดซ้ำได้ชุดใหม่ต่อด้านล่าง ลบชุดเก่าเอง
  • อัปเดต/ลบ ย้อนได้ด้วย Cmd+Z · จอที่ไม่มีใน Feature แล้วปลั๊กอินแค่รายงาน ไม่ลบเอง
  • มีปัญหา กด คัดลอก ที่แถบล่าง แล้วส่ง log ให้ทีม
วิธีใช้
วางลงบอร์ด
  1. เปิด node figma-export/serve.js ไว้
  2. ดูว่าบอร์ดที่เปิดอยู่ตรงกับปลายทาง ถ้าจะใช้บอร์ดนี้ กด "ตั้งบอร์ดนี้เป็นปลายทาง"
  3. ติ๊กชุดที่จะวาง (ติ๊กหัวกลุ่ม = ทั้ง Feature)
  4. กด วางลงบอร์ดนี้
ควรรู้
  • เปิดผิดบอร์ด กดวางครั้งแรกจะเตือนก่อน กดอีกครั้งถึงวาง
  • วางซ้ำ ชุดเดิมบนบอร์ดถูกแทน ของอื่นไม่ถูกแตะ
  • ไม่เห็นชุดใหม่ กด โหลดใหม่

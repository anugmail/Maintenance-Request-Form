# AC ฉบับใหม่ — Flow N

วันที่ 9 พฤศจิกายน 2569 · อ้างอิงปลั๊กอินปัจจุบัน · ดูเกณฑ์ร่วมและข้อรอยืนยันใน [ฉบับรวม](../AC-A-P-new.md).

## Flow N — S13 · กบค. นัดหมายหน่วยงานส่งคืนรถ

จำนวน 3 เฟรม

### N.1 — ฟอร์มนัดรับรถ (ค่าอู่ตั้งต้น)

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-N1-NEW-01 | เปิดนัดรับรถ | ใช้อู่จาก Purchase Order เป็นค่าตั้งต้น พร้อมผู้ประสานงานและเบอร์โทร |
| OH2-N1-NEW-02 | ดูวันนัด | ใช้ช่วงนัดรับรถตามแบบปัจจุบัน ไม่สลับเป็นวันเดียวของนัดเข้าอู่ |
| OH2-N1-NEW-03 | ดูปุ่ม | ย้อนกลับซ้าย ข้ามขั้นตอนและยืนยันนัดหมายขวา |
| OH2-N1-NEW-04 | กดข้าม | ไปขั้นข้อมูลปิดงานได้โดยไม่ต้องส่งนัดรับรถ |

### N.2 — รอหน่วยงานตอบรับ (toast 13)

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-N2-NEW-01 | ส่งนัดรับรถสำเร็จ | แสดงรอตอบรับพร้อม toast |
| OH2-N2-NEW-02 | ดูข้อมูลนัด | ช่วงวัน อู่ ผู้ประสานงาน และรถตรงข้อมูลที่ส่ง |
| OH2-N2-NEW-03 | ยังไม่ตอบรับ | ไม่แสดงว่าหน่วยงานรับรถหรือยืนยันรับรถแล้ว |

### N.3 — หน่วยงานปฏิเสธ (toast 16)

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-N3-NEW-01 | หน่วยงานปฏิเสธนัดรับรถ | แสดงเหตุผลของนัดนั้น |
| OH2-N3-NEW-02 | แก้ไข/ส่งใหม่ | มีทางดำเนินการต่อกับนัดรับรถเดิม ไม่ไปแก้นัดเข้าอู่ |
| OH2-N3-NEW-03 | ตรวจสถานะ | ไม่คงเป็นตอบรับแล้วจากการส่งนัดเดิม |

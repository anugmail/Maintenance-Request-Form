# AC ฉบับใหม่ — Flow O

วันที่ 9 พฤศจิกายน 2569 · อ้างอิงปลั๊กอินปัจจุบัน · ดูเกณฑ์ร่วมและข้อรอยืนยันใน [ฉบับรวม](../AC-A-P-new.md).

## Flow O — S14 · กบค. ปิดงาน

จำนวน 4 เฟรม

### O.1 — ยังไม่ได้ระบุอะไหล่

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-O1-NEW-01 | เปิดขั้นข้อมูลปิดงานที่ยังไม่มีอะไหล่ | แยกส่วนตัวรถกับเครื่องมือกล และมี empty state ของแต่ละหมวด |
| OH2-O1-NEW-02 | ดูค่าใช้จ่าย | ใช้หัวข้อ “ค่าใช้จ่ายในการดำเนินการ Overhaul” และมีช่องค่าแรง/ค่าใช้จ่ายตามแบบ |
| OH2-O1-NEW-03 | ดูทางเพิ่มอะไหล่ | มีการเพิ่ม/นำเข้ารายการตามแบบ ไม่สร้างแถวอะไหล่อัตโนมัติ |
| OH2-O1-NEW-04 | ดำเนินการปิดงาน | ต้องไปสรุป/ส่งอนุมัติก่อน ไม่ถือว่าปิดจริงเพียงกดปุ่มขั้นนี้ |

### O.2 — นำเข้าไฟล์ผิดรูปแบบ (validation ไม่ใช่ toast)

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-O2-NEW-01 | นำเข้าไฟล์ผิดรูปแบบ | แสดง validation ที่ส่วนไฟล์ ไม่ใช้ toast สำเร็จ |
| OH2-O2-NEW-02 | ตรวจข้อมูลอะไหล่ | ไม่เพิ่มแถวจากไฟล์ผิด และไม่ลบข้อมูลเดิมจากความผิดพลาดครั้งนี้ |

### O.3 — นำเข้าไฟล์สำเร็จ (toast 23)

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-O3-NEW-01 | นำเข้าไฟล์สำเร็จ | แสดงรายการในหมวดตัวรถ/เครื่องมือกลที่ถูกต้องพร้อม toast |
| OH2-O3-NEW-02 | ดูแต่ละแถว | ชื่อ จำนวน หน่วย และหมวดตรงข้อมูลที่นำเข้า |
| OH2-O3-NEW-03 | ตรวจยอด | ไม่สมมติราคาจากจำนวนเพียงอย่างเดียว; ราคาที่ไม่มีแสดงไม่มีข้อมูล |

### O.4 — บันทึกไม่สำเร็จ (toast 26)

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-O4-NEW-01 | บันทึกข้อมูลปิดงานไม่สำเร็จ | แสดง error toast |
| OH2-O4-NEW-02 | ตรวจขั้นงาน | ไม่เปลี่ยนเป็นปิดแล้วหรือส่งอนุมัติสำเร็จจากคำสั่งที่ล้มเหลว |
| OH2-O4-NEW-03 | ตรวจฟอร์ม | คงข้อมูลไว้ให้ตรวจแก้/ลองใหม่ |

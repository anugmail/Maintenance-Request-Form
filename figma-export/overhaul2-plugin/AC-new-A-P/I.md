## Flow I — S8 · กบค. ตรวจรับรถก่อน Overhaul

จำนวน 5 เฟรม

### I.1 — Default

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-I1-NEW-01 | เปิดตรวจรับรถ Default | แสดงรูปก่อน Overhaul ตามด้วย ReceiptChecklist ลงนามรับมอบ และปุ่มท้ายตามลำดับ |
| OH2-I1-NEW-02 | ดูรายการตรวจ | ใช้ checklist ต้นฉบับ 13 ข้อ มี/ไม่มี ชำรุด ผิดรุ่น และหมายเหตุ ไม่แทนด้วย checklist เก่า |
| OH2-I1-NEW-03 | ยังไม่ได้ลงนามครบ | ยืนยันรับรถ disabled |
| OH2-I1-NEW-04 | ยังไม่แนบรูป | ไม่มีภาพตัวอย่างที่ถูกอ้างว่าเป็นรูปของงานจริง |

### I.2 — Filled ตรวจ + เลือกผู้ลงนาม + ยังไม่ได้เซ็น

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|

| OH2-I2-NEW-02 | แนบรูปแล้ว | ภาพย่ออยู่ก่อน checklist พร้อมปุ่มลบเฉพาะรูป |
| OH2-I2-NEW-03 | เลือก “ไม่มี” ในข้อที่เกี่ยวข้อง | ชำรุด/ผิดรุ่น disabled ตามต้นฉบับ |
| OH2-I2-NEW-04 | ยังไม่เซ็นทั้งสองฝ่าย | ยืนยันรับรถ disabled |

### I.3 — เซ็นลงนาม Default

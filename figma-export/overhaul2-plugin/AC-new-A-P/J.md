## Flow J — S9 · กบค. เพิ่มการติดตามผลการดำเนินการ overhaul

จำนวน 3 เฟรม

### J.1 — ยังไม่มีความคืบหน้า

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-J1-NEW-01 | ยังไม่มีการติดตาม | แสดง empty state และปุ่มเพิ่มความคืบหน้า |
| OH2-J1-NEW-02 | ดูปุ่มซ่อมสำเร็จ | disabled เมื่อไม่มีรายการ |

### J.2 — เพิ่มความคืบหน้า

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-J2-NEW-01 | กดเพิ่มความคืบหน้า | modal มีวันที่/เวลา รายละเอียด หมายเหตุ optional และช่องตัวเลขเปอร์เซ็นต์พร้อม % คงที่ |
| OH2-J2-NEW-02 | กรอกเปอร์เซ็นต์ | รับ 0–100; ค่าว่าง ไม่ใช่ตัวเลข ติดลบ หรือเกิน 100 ต้องไม่ถูกบันทึกเป็นค่าถูกต้อง |
| OH2-J2-NEW-03 | บันทึกสำเร็จ | รายการใหม่อยู่ในตารางของรถคันนั้นพร้อมเปอร์เซ็นต์ที่กรอก |
| OH2-J2-NEW-04 | ยกเลิก modal | ไม่เพิ่มรายการติดตาม |

### J.3 — มีความคืบหน้า 2 รายการ

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-J3-NEW-01 | มีรายการติดตาม | ตารางมีวันที่ รายละเอียด progress หมายเหตุ และ action ของแต่ละแถว |
| OH2-J3-NEW-02 | รายการล่าสุดยังไม่ถึง 100% | ปุ่มซ่อมสำเร็จ disabled แม้รายการก่อนหน้าเคย 100% |
| OH2-J3-NEW-03 | รายการล่าสุดเป็น 100% | ปุ่มซ่อมสำเร็จ enabled |
| OH2-J3-NEW-04 | กดซ่อมสำเร็จและบันทึกสำเร็จ | ไป M.1 ขั้นตรวจสภาพ/เอกสาร Safety |

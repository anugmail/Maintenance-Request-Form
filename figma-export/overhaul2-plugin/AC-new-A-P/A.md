# AC ฉบับใหม่ — Flow A

วันที่ 9 พฤศจิกายน 2569 · อ้างอิงปลั๊กอินปัจจุบัน · ดูเกณฑ์ร่วมและข้อรอยืนยันใน [ฉบับรวม](../AC-A-P-new.md).

## Flow A — หน้ารายการแผน — ค้นหา · ตัวกรอง · ค้นไม่เจอ · ยังไม่มีแผน

จำนวน 8 เฟรม

### A.1 — รายการแผน

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-A1-NEW-01 | เปิด A.1 | หัวหน้าแสดง “จัดการงาน Overhaul” พร้อมแท็บ “แผน Overhaul” และ “รถที่ Overhaul”; แท็บแผนเป็น active |
| OH2-A1-NEW-02 | แสดงแถบจัดการเหนือรายการ | มีช่องค้นหา ปุ่ม “ตัวกรอง” และปุ่ม “สร้างแผน Overhaul”; ปุ่มสร้างอยู่ถัดจากตัวกรองด้านขวา |
| OH2-A1-NEW-03 | ช่องค้นหายังว่าง | แสดงข้อความ “ค้นหาเลขแผน, ชื่อแผน, เลขศูนย์ต้นทุน” และไม่แสดง pill ของคำค้นที่ยังไม่ได้ใช้ |
| OH2-A1-NEW-04 | มีรายการแผน | ตารางแสดงหมายเลขแผน ชื่อแผน ประเภทงบ ปีงบประมาณ งบประมาณ (บาท) ความคืบหน้า สถานะ วันที่สร้าง หมายเหตุ และช่องจัดการท้ายแถว |
| OH2-A1-NEW-05 | แสดงประเภทงบ | แสดงประเภทงบเป็นข้อความหลัก และรหัสงบของแผนนั้นเป็นบรรทัดรอง |
| OH2-A1-NEW-06 | แสดงงบประมาณและวันที่ | จำนวนเงินมี comma และทศนิยม 2 ตำแหน่ง เช่น 20,000,000.00; วันที่สร้างแสดงรูปแบบวัน/เดือน/ปี พ.ศ. ตามข้อมูลของแผนนั้น |
| OH2-A1-NEW-07 | มีข้อมูลเปอร์เซ็นต์รถครบใน Purchase Order ของแผน | ความคืบหน้าแผนเป็นค่าเฉลี่ยเปอร์เซ็นต์รถทุกคันรวมกัน โดยรถแต่ละคันมีน้ำหนักเท่ากัน; แสดง Progress bar และข้อความเปอร์เซ็นต์จริง ปัดเป็นจำนวนเต็มตามสูตร |
| OH2-A1-NEW-08 | ไม่มีข้อมูลรถหรือข้อมูลเปอร์เซ็นต์ไม่ครบสำหรับคำนวณ | แสดงเครื่องหมายไม่มีข้อมูล เช่น “-”; ไม่สมมติความคืบหน้าเป็น 0% หรือคำนวณจากเลขขั้นตอน |
| OH2-A1-NEW-09 | แสดงสถานะแผน | แสดง badge ตามค่าของแผน: “รอเลข PO”, “รอดำเนินการ” หรือ “เสร็จสิ้น”; ไม่ใช้ตำแหน่งแถวตัดสินสถานะ |
| OH2-A1-NEW-10 | แสดงหมายเหตุของแผน | มีข้อความหมายเหตุของแผนนั้น; ถ้าไม่มีข้อมูลแสดง “—” |
| OH2-A1-NEW-11 | แสดง action ท้ายแถว | มีปุ่ม “…” ให้เห็นและกดได้ในแต่ละแถว; ไม่ถูกคอลัมน์ชื่อแผนหรือหมายเหตุเบียดจนหาย |
| OH2-A1-NEW-12 | กดปุ่ม “…” ของแผน | แสดงเมนู “ดูรายละเอียด”, “แก้ไข” และ “ลบ”; การเลือกเมนูต้องอ้างแผนของแถวนั้น |
| OH2-A1-NEW-13 | กดสร้างแผน | เข้าฟอร์มสร้างแผนใหม่ B.1 โดยไม่โหลดข้อมูลของแผนจากแถวใดมาปะปน |
| OH2-A1-NEW-14 | กดตัวกรอง หรือเลือกแท็บรถ | กดตัวกรองเปิด A.2; เลือกแท็บรถไป A.5 และทำให้แท็บรถเป็น active; ไม่ค้าง active ที่แท็บแผน |
| OH2-A1-NEW-15 | ตารางมีข้อมูลหลายหน้า | มี pagination และเลือกจำนวนรายการต่อหน้า; ช่วงรายการและยอดรวมตรงกับข้อมูลที่ใช้แสดง ไม่ยึดจำนวนตัวอย่าง 10/96 เป็นค่าคงที่ |
| OH2-A1-NEW-16 | จำนวนคอลัมน์ของ Table ในไลบรารีไม่พอแสดงแยกทั้งหมด | ใช้รูปแบบสำรอง 8 คอลัมน์: ปีงบประมาณอยู่บรรทัดรองของงบประมาณ และหมายเหตุอยู่บรรทัดรองของชื่อแผน; ยังคงชื่อแผนและปุ่ม “…” ครบ ไม่ตัดข้อมูลนั้นทิ้ง |

### A.2 — ตัวกรอง

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-A2-NEW-01 | เปิดแผงตัวกรอง | แสดงปีงบประมาณค่าเริ่มต้น “ทั้งหมด” และหัวข้อ “งบประมาณ (บาท)” / “สถานะ” |
| OH2-A2-NEW-02 | แสดงงบประมาณ | เป็น checkbox 6 ช่วงวงเงินแบบข้อความ ไม่ใช่ List หรือ dropdown |
| OH2-A2-NEW-03 | แสดงสถานะ | มี checkbox พร้อม badge รอเลข PO รอดำเนินการ และเสร็จสิ้น โดยค่าเริ่มยังไม่เลือก |
| OH2-A2-NEW-04 | ดูท้ายแผง | มีล้างตัวกรอง ยกเลิก และตกลง; overlay คลุมความสูงของเฟรมจริง |

### A.3 — ค้นไม่เจอ

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-A3-NEW-01 | คำค้นไม่มีผลลัพธ์ | แสดง “ไม่พบแผน Overhaul” และข้อความอธิบายแทนตารางข้อมูล |
| OH2-A3-NEW-02 | ตรวจแถบค้นหา | ยังแสดงคำค้น/ตัวกรองที่ใช้และทางล้างเงื่อนไข ไม่ปนกับสถานะยังไม่มีแผน |
| OH2-A3-NEW-03 | กดล้างคำค้นและตัวกรอง | กลับสู่รายการตามเงื่อนไขที่ล้าง โดยผลรวมและ pagination อิงข้อมูลชุดใหม่ |

### A.4 — ยังไม่มีแผน

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-A4-NEW-01 | ยังไม่มีแผนในระบบ | แสดง “ยังไม่มีแผน Overhaul” และคำแนะนำให้สร้างแผน |
| OH2-A4-NEW-02 | ดูทางเข้าทำงาน | มีปุ่มสร้างแผน Overhaul ไม่แสดงแถวตัวอย่างเป็นข้อมูลจริง |
| OH2-A4-NEW-03 | กดสร้างแผน | เปิด B.1 ฟอร์มใหม่ |

### A.5 — รถที่ Overhaul

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-A5-NEW-01 | เปิดแท็บรถ | แท็บ “รถที่ Overhaul” active และมีช่องค้นหา/ตัวกรอง |
| OH2-A5-NEW-02 | ดูสรุปข้อมูล | แสดงกราฟเปรียบเทียบราคากลางกับประเมิน Overhaul, วงแหวน progress, Polar Area ประเภทรถ และอันดับยี่ห้อ |
| OH2-A5-NEW-03 | คำนวณราคา | ใช้รถที่มีราคาครบทั้งสองค่าในชุดเดียวกัน พร้อมจำนวนรถที่มีราคาครบ โดยไม่แสดงส่วนต่าง |
| OH2-A5-NEW-04 | คำนวณ progress | เฉลี่ยเฉพาะค่าที่มีข้อมูล 0–100 พร้อมจำนวนที่ขาด ไม่แทนข้อมูลขาดด้วย 0% |
| OH2-A5-NEW-05 | ดูตาราง | มีทะเบียน ข้อมูลรถ ราคากลาง ประเมิน Overhaul อายุการใช้งานเป็นคอลัมน์แยก ความคืบหน้า และทางดูรถ; เงิน comma และทศนิยม 2 หลัก; ไม่มีส่วนต่างและราคาซื้อเดิม |

### A.6 — ตัวกรองรถที่ Overhaul

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-A6-NEW-01 | เปิดตัวกรองรถ | แสดงแผงตัวกรองของรถ ไม่ใช้ชุดงบประมาณ/สถานะของรายการแผนแทน |
| OH2-A6-NEW-02 | ดูพื้นหลัง | แท็บรถยัง active และข้อมูลรถเดิมยังเป็นพื้นหลังของแผง |

### A.8 — รถที่ Overhaul — ไม่พบข้อมูลตามตัวกรอง

| รหัส AC ฉบับใหม่ | เมื่อ / เงื่อนไข | ผลที่ต้องได้ |
|---|---|---|
| OH2-A8-NEW-01 | กรองแล้วไม่พบรถ | แสดง “ไม่พบรถตามตัวกรอง” แทนแถวรถเดิม |

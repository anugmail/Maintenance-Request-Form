# A.2 — ตัวกรองรายการแผน

อ้างอิงภาพเจ้าของงานที่แนบใน session วันที่ 6 พ.ย. 2569 (480 × 1024)

- Side panel header: ตัวกรอง / กรองข้อมูลให้แสดงเฉพาะข้อมูลที่ต้องการ / ปุ่มปิด
- ปีงบประมาณ: Input dropdown ค่าเริ่มต้น ทั้งหมด ไม่มี Optional
- งบประมาณ (บาท): List with checkbox / List with checkbox item (Avatar=false, Supporting=false, Supporting 2=false) 6 รายการ ทุกข้อเริ่มไม่เลือก
  - น้อยกว่า 1,000,000
  - มากกว่า 1,000,000 - 5,000,000
  - มากกว่า 5,000,000 - 10,000,000
  - มากกว่า 10,000,000 - 15,000,000
  - มากกว่า 15,000,000 - 20,000,000
  - มากกว่า 20,000,000
- สถานะ: Checkbox with badge ทุกข้อเริ่มไม่เลือก: รอเลข PO (Gray) / รอดำเนินการ (Info) / เสร็จสิ้น (Success)
- Footer: ล้างตัวกรองซ้าย / ยกเลิกและตกลงขวา
- แผงกว้าง 480 ทางขวาของ desktop frame; overlay และแผงสูงตามเฟรมจริง ไม่จำกัด 1024
- ภาพมีเส้นคั่นหัว/ท้าย แต่คงปิด Divider ตาม R13 ที่ยังมีผล ไม่ยกเลิกกฎเส้นคั่นจากภาพเพียงอย่างเดียว
- แก้ regression หลังพบข้อความ component ไม่ครบ: เลิกใช้ key Checkbox with description `977a92…` ที่เพิ่มเป็น dependency บังคับโดยยังไม่ยืนยันการนำเข้า · ใช้ List with checkbox ที่ปลั๊กอินต้องโหลดอยู่เดิม · dump มี 5 ช่อง จึงใช้ instance ทั้งก้อน 2 ตัว (5+1 แถว) ซ่อนช่องที่เกิน ไม่เพิ่มลูกใน instance
- เป็นหน้าจอต้นแบบในปลั๊กอิน ไม่มี query/API หรือการคำนวณช่วงเงินจริง ถ้อยคำช่วงวงเงินถอดตามภาพนี้ ไม่เปลี่ยนกฎขอบเขตตัวเลขของระบบ

ภาพนี้แทนกฎ A.2 เดิมที่ใช้ dropdown ทั้ง 3 ช่อง และไม่แสดงรายการ dropdown งบประมาณลอยอีก

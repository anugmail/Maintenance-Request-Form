# T.1 — ยืนยันการส่งอนุมัติ

ต้นแบบ: ภาพที่เจ้าของงานแนบใน session วันที่ 6 พ.ย. 2569 ขนาด 1440 × 1528

- หัวรถ 72-6648 สงขลา → stepper 7 ขั้น (ขั้น 7 ยืนยันการส่งอนุมัติ) → สรุปสองคอลัมน์ → ย้อนกลับซ้าย / ส่งอนุมัติขวา
- ไม่มีข้อมูลยานพาหนะกล่องเดิมซ้ำระหว่างหัวหน้าและ stepper เฉพาะขั้น 7; ขั้นอื่นคงเดิม
- คอลัมน์ซ้ายประมาณ 59%: ข้อมูลผู้ซ่อม (อู่และเบอร์โทรแถวแรก ที่อยู่แถวถัดไป) / ประกัน (วันเริ่มและสิ้นสุดแถวแรก จำนวนวันแถวถัดไป) / บันทึกติดตาม (วันที่ รายละเอียด หมายเหตุ) / อะไหล่ที่ใช้งานและยอดรวม
- คอลัมน์ขวาประมาณ 41%: หัวยานพาหนะ / การ์ดรูปซ้ายข้อมูลขวา / เอกสาร Safety Inspection แบบอ่านอย่างเดียว
- รายการอะไหล่ใช้ Content item row / _Content item base Type Text ของไลบรารี ไม่ประกอบ Table cell เดี่ยว ไม่วาดเส้นคั่นตาม R13
- รูปข้อมูลอะไหล่: `[ชื่อ, จำนวน, หน่วย, หมวด, รหัส, ยอดเงินรายการ]`; ยอดเงินเป็นยอดต่อรายการแล้ว ห้ามคูณจำนวนซ้ำ
- ภาพตัวอย่างมี 5 รายการ รายการละ 2,500 บาท แต่ท้ายภาพแสดง 13,600 บาท ข้อมูลนี้ไม่สอดคล้องกัน สคริปต์คำนวณผลรวมจริง (5 × 2,500 = 12,500) ไม่คัดลอกยอด 13,600
- ข้อมูล PARTS เดิมไม่มีราคา จึงแสดงยอดรายบรรทัดและรวมเป็น “—” จนมีราคา; ไม่สร้างราคาสมมติให้รายการเดิม
- ตารางติดตามใช้รายการจาก logList ไม่สร้างแถว “Text” ตามข้อความ placeholder ในภาพ
- คง Safety 2 ไฟล์จากต้นแบบ; ข้อมูลไฟล์เป็น fixture ของปลั๊กอิน
- รูปรถยังเป็น placeholder เทา ไม่มีภาพต้นฉบับแยก ห้ามใช้ภาพทั้งจอเป็นภาพรถหรือพื้น UI
- เมื่อปิดงานแล้ว ไม่แสดงปุ่มส่งอนุมัติซ้ำ

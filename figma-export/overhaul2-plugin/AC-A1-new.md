# AC — A.1 รายการแผน Overhaul · ฉบับใหม่

วันที่: 9 พฤศจิกายน 2569

ขยายครบถึง P แล้ว: [AC ฉบับใหม่ทุกเฟรม A–P](AC-A-P-new.md) · [เลือกอ่านแยก Flow](AC-new-A-P/README.md). ข้อ A.1 ในไฟล์นี้ยังคงเนื้อหาและรหัสเดิม.

**ต้นฉบับที่ใช้:** A.1 “รายการแผน” ในปลั๊กอิน Maintain-D — Overhaul v2 ปัจจุบัน (`SCENARIOS[0][1][0]` → `listScreen('รายการแผน', CF_LIST)`). ฉบับนี้แยกจาก AC เดิมโดยใช้รหัส `OH2-A1-NEW-*`.

ขอบเขตเฉพาะ A.1 Desktop. การเปิดแผงตัวกรองเป็น A.2; ผลค้นหาไม่พบเป็น A.3; ยังไม่มีแผนเป็น A.4; dashboard แท็บรถที่ Overhaulเป็น A.5. เฟรมที่แก้มือใน Figma หลังสร้างอาจต่างจากสคริปต์ และยังไม่ได้ใช้เป็นต้นฉบับฉบับนี้.

**User story:** ในฐานะ กบค. ต้องการดูรายการแผน Overhaul พร้อมข้อมูลสำคัญและความคืบหน้า เพื่อเลือกดูรายละเอียด สร้าง หรือจัดการแผนที่ต้องการได้.

## ตัวอย่างตรวจสูตรความคืบหน้า

**Given** แผนมี Purchase Order สองใบ: ใบแรกมีรถ 100% จำนวน 1 คัน และใบสองมีรถ 0% จำนวน 3 คัน

**When** แสดงความคืบหน้าในแถวของแผน

**Then** แสดง **25%** จาก `(100 + 0 + 0 + 0) ÷ 4`.

**Given** ค่าเฉลี่ยของรถในแผนเท่ากับ 23%

**Then** ข้อความต้องแสดง **23%** แม้ component ของแท่งใช้ความยาวตาม variant ช่วง 20%.

## สิ่งที่ยังไม่กำหนดจาก A.1 เพียงเฟรมเดียว

- จังหวะค้นหา การจับคู่คำค้น และเงื่อนไขรวมหลายตัวกรอง: แยก AC เมื่อเลือกใช้ A.2/ผลค้นหา.
- ลำดับ sort เริ่มต้นและการสลับ sort: มีไอคอนในแบบ แต่ยังไม่ใช้สรุปกฎเรียงข้อมูล.
- สิทธิ์การแสดง/ซ่อน action และข้อห้ามลบตามสถานะ: ต้องยืนยันกติกาธุรกิจ.
- สูตรเปลี่ยนสถานะแผน: A.1 แสดงสถานะที่ได้รับ ยังไม่ยืนยัน transition จากเฟรมนี้.

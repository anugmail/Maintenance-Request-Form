# Card Calendar (Trello → FigJam)

วางการ์ดจาก CSV ลงปฏิทินบนบอร์ด FigJam เพื่อดูว่าแต่ละ UC ต้องเสร็จช่วงไหน (เพิ่ม 2 พ.ย. 2569)

## ใช้ยังไง

1. FigJam → Plugins → Development → **Import plugin from manifest…** → เลือก `figma-export/figjam-calendar-plugin/manifest.json`
2. เปิดปลั๊กอินในไฟล์ FigJam → เลือกไฟล์ CSV (เลือกได้หลายไฟล์พร้อมกัน เช่น การ์ด SP08 + backlog + export done)
3. ตั้ง sprint อ้างอิง (ค่าเริ่มต้น SP08 เริ่ม 2026-11-02 ยาว 2 สัปดาห์) และ "แสดงถึงเดือน" (ค่าเริ่มต้น 2027-02 = ก.พ. 2570 → คอลัมน์ไปจบ SP16) → กด **วางลงปฏิทิน**

รันซ้ำได้ — section `Card Calendar · Maintain-D` เดิม**ไม่ถูกลบ** แต่ถูก update ในที่เดิม: โหนดที่ชื่อตรงกับรอบก่อน (การ์ด/แถว UC/คอลัมน์ sprint/หัวตาราง ฯลฯ) ถูก reuse แค่ขยับตำแหน่ง/resize/เปลี่ยนสี-ข้อความ ส่วนโหนดเดิมที่ไฟล์ CSV รอบนี้ไม่มี (เช่น เลือกไฟล์ไม่ครบ) **ไม่ถูกลบ** ปล่อยอยู่กับที่เสมอ — ถ้าอยากให้บอร์ดตรงกับ Trello 100% ต้องเลือก CSV ให้ครบทุกไฟล์ที่เคยใช้วางมาก่อนในรอบเดียวกัน ไม่ใช่ปล่อยให้ plugin ลบของเก่าเอง

## หัวตาราง 3 ชั้น (แบบ A · 2 พ.ย. 2569)

1. **แถบเดือน** — แบ่งตรงวันที่ 1 จริง sprint ที่คร่อมเดือน (เช่น SP10 30 พ.ย. – 11 ธ.ค.) จึงถูกแบ่งสองเดือน · เดือนปัจจุบันสีเขียว
2. **แถบสัปดาห์** — จันทร์–อาทิตย์ · สัปดาห์ปัจจุบันสีเขียว · เส้นแดง "วันนี้" ใช้สเกลเดียวกัน
3. **หัว sprint** — ชื่อ · ช่วงวันทำงาน (จันทร์–ศุกร์) · จำนวนการ์ด · แต้มรวมต่อทีม

## อ่านการ์ดยังไง

| ข้อมูล | อ่านจาก |
|---|---|
| แถว (UC) | เลขในชื่อ `[PEA-1.<UC>.<n>]` **หรือ** `[MD-JO<n>-UC-<UC>(-<sub>)]` (ของที่ยังไม่มีเลข PEA จริง — export จาก project_timeline_1760 เช่น `JO1-JO2-JO3-ยังไม่มีการ์ด.csv`) · ทั้งสองแบบชี้แถวเดียวกันได้ (`UC-07` = `1.7` เหมือน `PEA-1.7.n`) · ชื่อ UC ตาม `UC_NAMES` ใน code.js |
| คอลัมน์ (sprint) | `[SP08]` ในชื่อ · `[SPxx]` → คอลัมน์ "ยังไม่ลง sprint" · การ์ด Done ที่ไม่มี sprint → คอลัมน์ "Done · ไม่ระบุ sprint" |
| ช่วงวันที่ | SPn = วันเริ่ม sprint อ้างอิง + (n − อ้างอิง) × ความยาว · จันทร์ถึงศุกร์สัปดาห์สุดท้าย |
| สีการ์ด | Labels มี ⭐️ = เหลือง · ❤️ = ชมพู · ไม่มี = ฟ้า · Current List มี Done/Complete = เทา + ✓ |
| แต้ม | Labels `3pt` → รวมต่อทีมที่หัวคอลัมน์ |

ข้ามโดยค่าเริ่มต้น: แถว template (`X.X.X`) · การ์ด `[Defect]` · การ์ดที่ไม่มีเลขทั้งสองแบบ (`[PEA-x.x.x]` และ `[MD-JOn-UC-x]`) (ติ๊กให้รวมได้ในหน้าต่าง)
การ์ดเลขซ้ำจากหลายไฟล์นับใบเดียว — ใบที่ Done ชนะ (เทียบด้วย `no` ซึ่งคนละ namespace กันระหว่างเลข PEA กับเลข MD-JO จึงไม่ชนกันเอง)

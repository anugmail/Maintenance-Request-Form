# Feature ติดตามและแดชบอร์ด: journey หน้า และ case สำหรับทีม dev

> ร่าง 17 พ.ย. 2569 ตามรูปแบบเดียวกับ Feature แผนบำรุงรักษา (ไฟล์ 32)
> ลอกเนื้อหาจากงานเดิม (userflow ไฟล์ 14 Scenario 4 และ 24 · จอใน `figma-export/maintainance-plugin/screens.js` บล็อก C และ W) มาจัดใหม่ ไฟล์เดิมไม่ได้แก้

## 0. กติกาของเอกสารนี้

### 0.1 ชั้นของงาน

- **Feature** ก้อนงานที่ทีม dev รับไปทำ ประกอบด้วยหลายหน้า
- **Journey** งานหนึ่งเรื่องที่ผู้ใช้ตั้งใจทำ ครอบหน้าที่เกี่ยวข้องและทางเปลี่ยนหน้า
- **หน้า** หน้าจอที่ dev ต้องสร้าง
- **case** หน้าตาแบบหนึ่งของหน้านั้น

### 0.2 ไม่สร้างหน้าซ้ำ

1. **Toast สร้างเป็นชิ้นเดียว ไม่สร้างทั้งหน้าซ้ำ** ทุก toast เป็น component Notification ของไลบรารีชิ้นเดียว มีป้ายบอกว่า **แสดงบนหน้าไหน เมื่อไหร่** ตัวอย่าง: toast "ส่งออกไฟล์สำเร็จ" แสดงบนหน้าอะไหล่ของแผนที่อนุมัติแล้ว เมื่อกดส่งออกใน popup แล้วสร้างไฟล์สำเร็จ ไม่ต้องสร้างหน้าแดชบอร์ดที่มี toast ขึ้นมาอีกจอ ตำแหน่งบนจอจริงคือมุมขวาบนเสมอ
2. **case ที่หน้าตาเหมือนกันสร้างครั้งเดียว** journey อื่นที่ใช้ case นั้นอ้างรหัสจอเดิม ไม่สร้างใหม่
3. **case ที่หน้าเปลี่ยนจริง ยังสร้างเต็มหน้า** เช่น กรองแล้ว ชิปตัวกรองขึ้นเหนือตารางและแถวในตารางเปลี่ยน ต้องมีจอของสภาพนั้น แต่ toast ที่ขึ้นพร้อมกันแยกเป็นชิ้น

### 0.3 ชื่อ case มาตรฐาน

| case | ความหมาย |
|---|---|
| Default | เปิดหน้าครั้งแรก ยังไม่มีข้อมูล หรือยังไม่กรอก |
| Filled | มีข้อมูล หรือกรอกครบแล้ว |
| Interaction | ระหว่างใช้งาน เช่น เปิดรายการเลือก แผงตัวกรอง popup เมนู |
| Empty result | ค้นหาหรือกรองแล้วไม่พบ |
| Disabled | ปุ่มกดไม่ได้เพราะเงื่อนไขยังไม่ครบ |
| Error Validation Field | ช่องที่ต้องกรอกยังว่าง แสดง error ตอนออกจากช่อง |
| Confirm | หน้าต่างยืนยันก่อนทำต่อ |
| Role · Status | หน้าตาต่างกันตามบทบาทผู้ใช้ หรือสถานะของข้อมูล |
| Toast | ชิ้นแยก ตามข้อ 0.2 |

### 0.4 รหัสจอ

ในเอกสารนี้ใช้รหัสจอเดิมของ `screens.js` (C.1 W.7 …) เพื่อเทียบกับชุดเดิมได้ · บล็อก C = Scenario 4 · บล็อก W = Scenario 24 · ใน Figma แต่ละจอมีรหัสตามชั้นเพิ่ม (journey.หน้า.case เช่น 1.1.2) และวงเล็บรหัสจอเดิมท้ายป้าย

## 2. Journey

แต่ละ journey มี 3 ส่วน: ทางเดิน (action แล้วไปหน้าไหน) · case ของแต่ละหน้าตามลำดับที่เดิน · toast ของ journey

### J1 ดูอะไหล่และความคืบหน้าของแผนที่อนุมัติแล้ว

**ทางเดิน**

| # | อยู่หน้า | ทำอะไร | ผล | ไปหน้า |
|---|---|---|---|---|
| 1 | อะไหล่ของแผนที่อนุมัติแล้ว | เปิดหน้า | มีแผนที่อนุมัติแล้ว | อยู่หน้าเดิม แท็บรวมตามรายการ |
| 1.1 | อะไหล่ของแผนที่อนุมัติแล้ว | เปิดหน้า | ยังไม่มีแผนที่อนุมัติแล้ว | อยู่หน้าเดิม Empty state |
| 2 | อะไหล่ของแผนที่อนุมัติแล้ว | ค้นหา หรือกดตัวกรอง เลือกแล้วกดตกลง | พบ | อยู่หน้าเดิม ชิปตัวกรองเหนือตาราง |
| 2.1 | อะไหล่ของแผนที่อนุมัติแล้ว | ค้นหา หรือกรอง | ไม่พบ | อยู่หน้าเดิม Empty state ไม่พบข้อมูล |
| 3 | อะไหล่ของแผนที่อนุมัติแล้ว | สลับแท็บแยกรายคัน หรือความคืบหน้าของแผน | | อยู่หน้าเดิม |
| 4 | อะไหล่ของแผนที่อนุมัติแล้ว | แท็บความคืบหน้าของแผน กดไอคอน > ของแถว | | หน้าไตรมาสของแผน (Feature แผนเดินทาง) |

**หน้าอะไหล่ของแผนที่อนุมัติแล้ว** (8 จอ)
- Default ยังไม่มีแผนที่อนุมัติแล้ว Empty state "ยังไม่มีแผนที่อนุมัติแล้ว" (C.13)
- Filled แท็บรวมตามรายการ Metric 4 ใบ ตารางเรียงได้ทุกคอลัมน์ (C.1)
- Filled ค้นหาชื่อหรือรหัสอะไหล่ (C.2)
- Interaction แผงตัวกรอง ปีงบประมาณ หน่วยงานผู้ขอเบิก เขต แผน (C.3)
- Filled กรองแล้ว ชิปตัวกรองเหนือตาราง (C.4)
- Empty result ไม่พบอะไหล่ที่ตรงกับคำค้นหรือตัวกรอง (C.5)
- Filled แท็บแยกรายคัน 1 แถว = อะไหล่ 1 รายการของยานพาหนะ 1 คัน (C.6)
- Filled แท็บความคืบหน้าของแผน 1 แถว = 1 ไตรมาสของ 1 แผน (C.7)

ไม่มี toast

### J3 ติดตามการบำรุงรักษารายคันและกำหนดครั้งถัดไป

**ทางเดิน**

| # | อยู่หน้า | ทำอะไร | ผล | ไปหน้า |

**หน้าข้อมูลยานพาหนะ แท็บการบำรุงรักษา** (6 จอ)

- Interaction แผงตัวกรอง ประเภทยานพาหนะ สังกัดยานพาหนะ สถานะกำหนดการ รายการที่ครบกำหนด (W.4)
- Filled กรองแล้ว ใกล้ครบกำหนดบำรุงรักษา (W.5)
- Interaction เมนู … ของยานพาหนะ ดูรายละเอียด (W.6)

**หน้ารายละเอียดยานพาหนะ แท็บตารางบำรุงรักษา** (2 จอ)

- Interaction เมนู … ของประวัติ ดูรายละเอียด (W.8)
- Default ยานพาหนะที่ยังไม่มีประวัติการบำรุงรักษา **ยังไม่มีจอ**


## 5. ยังไม่มีจอ (ส่งให้เจ้าของงานตัดสิน)

1. toast ส่งออกไม่สำเร็จ
2. ไฟล์ Excel ชีตความคืบหน้าของแผน (popup บอกว่า Excel 1 แท็บ 1 ชีต แต่มีจอแค่ 2 ชีต)
3. ไฟล์ PDF ของแท็บแยกรายคัน และแท็บความคืบหน้าของแผน
4. หน้าอะไหล่ของแผนที่อนุมัติแล้ว: ค้นหาหรือกรองในแท็บแยกรายคันและแท็บความคืบหน้า (ตอนนี้มีจอค้นหาของแท็บรวมตามรายการเท่านั้น)
5. รายละเอียดยานพาหนะ: ยานพาหนะที่ยังไม่มีประวัติการบำรุงรักษา และยานพาหนะที่ไม่ใช่เครนหรือกระเช้า (ไม่มีแถว Safety Inspection)
6. ข้อมูลยานพาหนะ แท็บการบำรุงรักษา: มุมหน่วยงานเจ้าของยานพาหนะ เห็นเฉพาะยานพาหนะในสังกัด

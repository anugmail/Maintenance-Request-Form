> ค่าของ Feature อยู่ที่ `figma-export/maintainance-feature-plugin/features/job.js`

## 0. กติกาของเอกสารนี้

### 0.1 ชั้นของงาน

- **Feature** ก้อนงานที่ทีม dev รับไปทำ ประกอบด้วยหลายหน้า
- **Journey** งานหนึ่งเรื่องที่ผู้ใช้ตั้งใจทำ ครอบหน้าที่เกี่ยวข้องและทางเปลี่ยนหน้า
- **หน้า** หน้าจอที่ dev ต้องสร้าง
- **case** หน้าตาแบบหนึ่งของหน้านั้น

### 0.2 ไม่สร้างหน้าซ้ำ

1. **Toast สร้างเป็นชิ้นเดียว ไม่สร้างทั้งหน้าซ้ำ** ทุก toast เป็น component Notification ของไลบรารีชิ้นเดียว มีป้ายบอกว่า **แสดงบนหน้าไหน เมื่อไหร่** ตัวอย่าง: toast "ส่งออกไฟล์สำเร็จ" แสดงบนหน้ารายละเอียดแผนเดินทาง เมื่อส่งออกแผนเดินทางสำเร็จ ไม่ต้องสร้างหน้ารายละเอียดแผนเดินทางที่มี toast ขึ้นมาอีกจอ ตำแหน่งบนจอจริงคือมุมขวาบนเสมอ
2. **case ที่หน้าตาเหมือนกันสร้างครั้งเดียว** journey อื่นที่ใช้ case นั้นอ้างรหัสจอเดิม ไม่สร้างใหม่
3. **case ที่หน้าเปลี่ยนจริง ยังสร้างเต็มหน้า** เช่น ปิดงานรายคันแล้ว สถานะของคันนั้นและตัวนับ "ตรวจแล้ว" ในหน้ารายละเอียดแผนเดินทางเปลี่ยน ต้องมีจอของสภาพนั้น แต่ toast ที่ขึ้นพร้อมกันแยกเป็นชิ้น

### 0.3 ชื่อ case มาตรฐาน

| case | ความหมาย |
|---|---|
| Default | เปิดหน้าครั้งแรก ยังไม่มีข้อมูล หรือยังไม่กรอก |
| Filled | มีข้อมูล หรือกรอกครบแล้ว |
| Interaction | ระหว่างใช้งาน เช่น เปิดรายการเลือก ปฏิทิน popup เมนู |
| Empty result | ค้นหาหรือกรองแล้วไม่พบ |
| Disabled | ปุ่มกดไม่ได้เพราะเงื่อนไขยังไม่ครบ |
| Error Validation Field | ช่องที่ต้องกรอกยังว่าง แสดง error ตอนออกจากช่อง |
| Confirm | หน้าต่างยืนยันก่อนทำต่อ |
| Role · Status | หน้าตาต่างกันตามบทบาทผู้ใช้ หรือสถานะของงาน |
| Toast | ชิ้นแยก ตามข้อ 0.2 |

## 5. ยังไม่มีจอ (ส่งให้เจ้าของงานตัดสิน)

1. บันทึกงานรายคัน: Confirm ยืนยันการตรวจสภาพ และยืนยันปิดงาน (จอเดิมไปขั้นถัดไปเลย)
2. toast บันทึกไม่สำเร็จ (general error) ของการเริ่มงาน ปิดงาน บำรุงรักษาไม่ได้ ส่งตรวจงาน บันทึกผลตรวจน้ำมัน ยอมรับผล
3. ฝั่งผู้รับจ้าง: Step 1 บำรุงรักษาไม่ได้ (มีเฉพาะ Step 2) · ส่งตรวจงานใหม่หลังถูกส่งกลับแก้ไข · toast ส่งตรวจงานใหม่
4. ฝั่งผู้ตรวจรับงานของผู้รับจ้าง (S11 ยังตัด ผู้ตรวจรับยังไม่เคาะ)
5. การตรวจบำรุงยานพาหนะรอตรวจสอบ: Default ไม่มีรายการ · Empty result ค้นหาไม่พบ
6. หลักฐานทั้งแผน: Disabled ยังไม่ประเมิน ปุ่มยอมรับผลกดไม่ได้ · Error Validation Field
7. ผลการตรวจรายคัน: ไม่ยอมรับผล หรือส่งกลับ (มีเฉพาะยอมรับผล)

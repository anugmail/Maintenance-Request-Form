# A.5 mock ที่เทียบกับ UAT — 11 พฤศจิกายน 2569

เปิด `overhaul-a5-prototype.html` ผ่าน `python3 -m http.server 8123 --bind 127.0.0.1` แล้วใช้ URL `http://127.0.0.1:8123/design-mock/overhaul-a5-prototype.html`. แท็บแผนเปิดตรงด้วย `?tab=plans`.

เป้าหมายคือให้ข้อมูลและรูปแบบใกล้หน้า [UAT Overhaul](https://vms-plus-uat.odds.team/maintain-d/overhaul-utility-vehicle) โดยรักษา feedback ล่าสุดของ A.5. A.5/กราฟและคอลัมน์ราคาเป็นแบบเสนอเพิ่มตาม feedback; หน้า UAT ปัจจุบันยังแสดงรายการแผนเป็นทางเข้าหลัก.

## ที่มาข้อมูล

- `overhaul-a5-uat-data.js` เป็น snapshot อ่านอย่างเดียววันที่ 11 พฤศจิกายน 2569. เก็บเฉพาะฟิลด์แผน/รถที่ใช้แสดงผล ไม่มี cookie, token, รายชื่อผู้ใช้ หรือข้อมูลติดต่อส่วนบุคคล.
- แท็บแผนใช้ชื่อ เลขแผน ปีงบ ประเภทงบ งบประมาณ สถานะ วันที่สร้าง และความคืบหน้าตาม UAT รวม 27 แผน; เรียงตั้งต้นตามผลลัพธ์ UAT. เงินเป็น comma และ 2 ตำแหน่ง.
- แท็บรถใช้ทะเบียน รุ่น ประเภท หน่วยงาน อายุ และสถานะจากแผน ORZ6900026 / Test PO-001. สาม Purchase Order มีรถที่ผูกอยู่ 9 รายการ รวมรถไม่ซ้ำ 8 คัน. ทะเบียน 84-6932 อยู่ 2 PO จึงแสดงเป็นรถ 1 คัน พร้อมเก็บทั้งสอง PO ในรายละเอียด.
- อายุใช้ข้อความปีและเดือนจาก UAT. อายุเฉลี่ยคำนวณจากเดือนของรถหลังกรอง. ไม่ลดอายุในตารางเหลือเฉพาะจำนวนปีเต็ม.
- UAT snapshot ไม่มีฟิลด์ราคากลาง/ประเมิน Overhaul ในหน้ารายการรถที่ตรวจ. เก็บเป็น null และแสดง — ในตาราง รายละเอียด และ Dashboard ตามตัวเลือกของผู้ใช้. ไม่ใส่ราคาตัวอย่าง และไม่แทนข้อมูลที่ขาดด้วย 0.00. เมื่อมีค่าจริง format เงินยังคงเป็น comma และทศนิยม 2 ตำแหน่ง รวมถึงค่า 0 เป็น 0.00.
- ไม่มีเปอร์เซ็นต์รายคันใน snapshot จึงแสดง — พร้อม coverage 0/8 คัน ไม่ใช้สถานะนัดหมายหรืออัตราปิด PO มาคาดเดาเปอร์เซ็นต์.

## รูปแบบและ behavior

ใช้ sidebar/topbar, breadcrumb, typography, สีตัวอักษรตาราง, ปุ่มค้นหา/ตัวกรอง, badge และ pagination จาก component/Tailwind ของโครงการ เทียบภาพและข้อมูลหน้า UAT จริง. ที่มาเดิม: (Component) VMS Plus / UI VMS Plus Release#2 — Contract list, Filter Side panel, MA Overview ตาม component map. ไม่เพิ่ม CSS หรือแก้ global tokens.

คอลัมน์รถตาม feedback ล่าสุด: ทะเบียน / ข้อมูลรถ / ราคากลาง / ประเมิน Overhaul (บาท) / อายุการใช้งาน / ความคืบหน้า / รายละเอียด. ข้อมูลรถมีรุ่น ประเภท และหน่วยงาน. ไม่มีส่วนต่างประมาณการหรือราคาซื้อเดิม. จำนวนเงินชิดขวาและใช้ทศนิยม 2 ตำแหน่งเสมอเมื่อมีค่า.

ลองค้นหา กรอง เปลี่ยนแท็บ แบ่งหน้าแผน เรียงเลข/ชื่อแผน และดูรายละเอียดแผน/รถได้. ตัวกรองเป็น draft จนกดตกลง; ยกเลิกไม่เปลี่ยนตาราง. กราฟ จำนวนรถ และตารางใช้รถหลังกรองชุดเดียวกัน. รายละเอียดของแผน ORZ6900026 แสดง 3 PO และเปิดแท็บรถของแผนได้; แผนอื่นยังไม่มี snapshot รายละเอียดรถใน mock ชุดนี้. ไม่มีการสร้าง แก้ไข ลบ หรือส่งข้อมูลเข้า UAT.

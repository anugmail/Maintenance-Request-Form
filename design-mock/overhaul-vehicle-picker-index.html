รวม mock — เลือกรถเข้าแผน Overhaul

ข้อเสนอแยก "เลือกรถ" (ติ๊กชั่วคราว ยังไม่ลง DB) ออกจาก "ตารางรถในแผน + ราคารายคัน" (ลง DB พร้อมแผนตอนบันทึก) · ข้อมูลจำลองทั้งหมด

ข้อเสนอให้เลือก 2
แบบ 1 · Modal + แผงตัวกรองกางต้องขอ component เพิ่ม

กด "เพิ่มรถ" → modal บนหน้าฟอร์ม · ปุ่ม "ตัวกรอง" กางแผงลงใต้ช่องค้นหาในกล่อง · ไม่ต้องออกจากฟอร์ม

  • อ้างอิง: SAP Fiori Value Help Dialog (ซ่อนตัวกรองเป็นค่าตั้งต้น + ปุ่มแสดง/ซ่อนในตัว dialog)
  • ไลบรารี VMS Plus ยังไม่มีแผงตัวกรองแบบกาง และ Modal xl สำหรับตาราง
เปิดโหมดสร้างแผน โหมดแก้ไข (แผน 123456)
แบบ 2 · หน้าเต็ม + Side panelมี component ในไลบรารีครบ

กด "เพิ่มรถ" → หน้า "เลือกรถเข้าแผน" · แท็บ รถที่เลือกได้ / ที่เลือก / อยู่ในแผนนี้แล้ว · ตัวกรองเป็น Side panel แบบหน้ารายการแผน · ยืนยันแล้วกลับฟอร์มพร้อมข้อมูลเดิม

  • ไลบรารี: Side panel › Filter_Panel (1964:13912) · Table header Desktop (2003:270) · Tabs · Table
  • ข้อเสีย: ต้องออกจากฟอร์มไปอีกหน้า แล้วพาค่ากลับ
เปิดโหมดสร้างแผน โหมดแก้ไข (แผน 123456)

ตารางสะพาน — ขนาดหน่วยงาน ↔ dept_sap

ต่อผัง โครงสร้างหน้างาน 74 จังหวัด (PDF) เข้ากับตาราง vms_mas_department ของระบบ — PDF มี ขนาด L/M/S/XS ที่ระบบไม่มี ส่วนระบบมี dept_sap ที่ PDF ไม่มี หน้านี้คือตารางกลางที่รอเติมช่อง dept_sap เมื่อได้ dump มา
วิธี join — match_key เป็นกุญแจแบบ lossy ที่สมมาตร: ตัดคำนำหน้า/จุด แล้วยุบ ำ → า ฝั่งระบบต้อง fold แบบเดียวกัน จึงจะ match ได้แม้ชื่อฝั่ง PDF จะเพี้ยนจาก font subset (PDF สำรภี → สารภี · ระบบ สารภี → สารภี ตรงกัน)
ต้อง join ด้วยคู่ (จังหวัด + match_key) ไม่ใช่ key เดี่ยว — มีชื่ออำเภอซ้ำข้ามจังหวัด ท่าตูม×2 · ท่าเรือ×2 · เฉลิมพระเกียรติ×3 ในระดับ (เวอร์ชัน + จังหวัด + key) ไม่ซ้ำเลยสักแถว
คอลัมน์ ✓ = ยืนยันชื่อแล้วหรือยัง — Y เฉพาะระดับ กฟจ. ที่เทียบกับรายชื่อ 74 จังหวัดจริงแล้ว · N คือชื่ออำเภอที่ยังยืนยันสระไม่ได้ ห้ามเอาชื่อแถว N ไปแสดงผลให้ผู้ใช้ ใช้ได้แค่ช่วยไล่จับคู่

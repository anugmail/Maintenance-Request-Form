6 · วิธีเรียกใช้

<!-- ระดับ -->
<button class="btn btn-s">รอง — ขอบเทา</button>
<button class="btn btn-t">ลำดับสาม — ไม่มีพื้น</button>
<button class="btn btn-link">ลิงก์สีแบรนด์</button>
<button class="btn btn-d">ยกเลิก (destructive)</button>

<!-- สถานะ -->
<button class="btn btn-p" disabled>ปิดใช้งาน</button>
<button class="btn btn-p is-loading">กำลังส่ง…</button>  <!-- สปินเนอร์มาเอง -->
Focused ไม่ต้องเขียนอะไร — :focus-visible ใส่วงแหวนให้เองตอนกด Tab

7 · ยังค้าง

• 2 ค่าสีรอยืนยัน — destructive hover และ Link color (ติด rate limit ตอนอ่าน)
• gray-500 / 900 / 950 ยังไม่ได้อ่านจาก Figma ใช้ค่ามาตรฐาน Untitled UI v2 ไปก่อน
• คอมโพเนนต์อื่นในไลบรารี ที่ยังไม่ได้ดึง — Text input · Number input · Input dropdown · Text area · Badge outline/color · Pill · Table cell · Mobile table item · Indicator · Modal · Checkbox
• Shape=Round ไลบรารีมี แต่ต้นแบบยังไม่ได้ใช้

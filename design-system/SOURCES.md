- **บัญชีเป็น Figma Starter plan** ⇒ MCP มีเพดานเรียกต่อช่วงเวลาต่ำมาก · เซสชัน 11 ส.ค. ใช้ไป **4 call ก็ตัน** (`whoami` → `create_new_file` → `get_metadata` → `search_design_system`)

## ขั้นตอนเมื่อโควตากลับมา

1. `get_metadata` ทีละ node → รู้ว่าหน้านั้นคืออะไร มีคอมโพเนนต์อะไร
2. `get_design_context` เฉพาะ node ที่มีค่าที่เราต้องใช้ → ได้ค่าจริง
3. เทียบกับ `tokens.css` / `components.css` → **บันทึกทั้งที่ตรงและที่ผิด** (รอบปุ่มเจอผิด 2 เรื่อง: hover ปุ่มหลัก · gray ramp ทั้งแถบ)
4. อัปเดตค่า + เปลี่ยนเครื่องหมาย `~`/`⚠` เป็น `✔` + บั๊ม `?v=` + Changelog
5. อัปเดตตารางสถานะในไฟล์นี้
